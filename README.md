# Q-Bert_RL
This repository contains a project of reinforcement learning on the game Q*Bert using observation extracting from the RAM.
This project was developed for the course of "Artificial Intelligence" at University Of Salerno.

## How To Run the project
To run project locally, follow this procedure:
- Clone repository on your pc
- Install all requiremnts with
  > pip install requirements.txt -r
- Execute any file you want.
  
**Note**: to run the jupyther notebook you can simply use Google Colab.
